SAVANNA BREW CAFÉ — HTML & CSS ASSIGNMENT 1
Course: Introduction to Web Development

OPEN THE WEBSITE
1. Extract the ZIP file first.
2. Open savanna-brew/index.html in a browser.
3. Navigate through Home, About, Menu, Gallery and Contact.
4. Use browser Developer Tools to inspect the layouts at different widths.

CONTENTS
index.html         Home, welcome text, three favourite cards and booking link
about.html         Founder, supplied café story, values and quotation
menu.html          Three price tables with the exact supplied menu data
gallery.html      Eight figures with descriptive captions
contact.html       Reservation enquiry, contact details and opening hours
css/style.css      One shared stylesheet, including the responsive layouts
images/            Local artwork and photographs used by the five pages

IMPLEMENTATION
- HTML5 and CSS only: no JavaScript, inline CSS or CSS framework.
- Semantic headings, navigation, content sections and footer are included.
- Navigation uses Flexbox; the gallery uses CSS Grid (4/2/1 columns).
- At 768px and below, the navigation stacks beneath the logo.
- The menu tables scroll within their own wrappers on narrow screens.
- All images have alt text, correct file paths and matching dimensions.
- Form labels, required fields and native email validation are included.
- Reduced-motion styling and visible keyboard-focus outlines are included.
- A subtle CSS-only fade-in provides the optional animation feature.

IMPORTANT DEMONSTRATION LIMITATIONS
- Savanna Brew Café and its contact details are fictional, per the brief.
- The HTML-only form prepares an email using mailto: and cannot confirm
  or save bookings. Its .example receiving address is deliberately fictional.
- Social links open the social platforms rather than verified café profiles.
- The bundled café visuals are generated illustrations, not documentary
  photographs of an actual café or owner.
